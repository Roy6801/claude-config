# Pickup templates

## PR plan

```markdown
<!-- pr: <project>/<slug>/<pr-name> -->
# <pr-name>: <one-line outcome>

## Does
One or two sentences, behaviour-level.

## Requirements
- <what it must do>. Checked by: <test, browser check, number, screenshot>.

## Commits
### 1. <type(scope): title>
- Why: one sentence.
- Files: the exact files and the functions or components touched, verified against the code.
- Change: what changes, in behaviour and structure, in plain words.
- Contracts: only the signatures, types or API shapes other code or later PRs depend on, as short snippets.
- Test: what it asserts.

## Size
About <n> lines of code, tests outside the count.

## Evidence
What the PR body will show, and how it is captured.

## Unresolved questions
```
